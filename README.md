# Noor Portfolio

A modern and responsive personal portfolio website built to showcase my projects, skills, and professional background as a software developer. The website provides an overview of my work, technical expertise, and ways to get in touch.

## Live Demo

https://portfolio-afc4f.web.app/

## About the Project

This portfolio website was developed to present my personal projects, technical skills, and experience in a clean and professional way. The design focuses on responsiveness, performance, and user experience across different devices.

## Features

* Responsive design for desktop, tablet, and mobile devices
* Modern and clean user interface
* Projects showcase section
* About Me section
* Contact section with social links
* Optimized performance and fast loading times

## Technologies Used

* React.js
* Vite
* Tailwind CSS
* Firebase Hosting

## Installation

Clone the repository:

```bash
git clone https://github.com/no2rkhalid-Pro/Portfolio.git
```

Navigate to the project directory:

```bash
cd Portfolio
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

## Build for Production

```bash
npm run build
```

## Deployment

This project is deployed using Firebase Hosting.
